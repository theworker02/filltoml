# filltoml

Fill validation gates for toml inputs before they hit prod.

**Site:** https://theworker02.github.io/filltoml/

## Install / run

```bash
git clone https://github.com/theworker02/filltoml.git
cd filltoml
node src/cli.js
node --test
```
